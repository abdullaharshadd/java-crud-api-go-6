- [info] **inconsistent-pattern**: internal/model/user.go defines PostgreSQL DDL plus DialectFromURL and advertises Postgres support. However, internal/repository/user.go can only talk to MySQL: every query quotes identifiers with backticks and relies on LastInsertId and FOR UPDATE written the MySQL way. cmd/server/router.go also hard-codes model.DialectMySQL and the mysql driver, and never calls DialectFromURL. As a result the Postgres branch can never be reached, and it would break if someone wired it up. Either remove it or make the repository dialect-aware.
